# Korean Practice: Hangul Review + Unit 2

## Local testing
Extract the whole ZIP into a new folder, then double-click index.html.
Keep all files and folders together. No internet connection is required.

The home page opens Hangul Review or Unit 2. Both have a link back home
and a link to the other section.

Hangul Review retains its original 70 cards, audio, and listening quiz.
Unit 2 contains 41 cards, the latest Expressions and Grammar corrections,
and its 12-question quiz. All 112 MP3 recordings are included.

## Files to upload after local testing
Use the contents of this folder, not the ZIP itself or its enclosing folder.

Replace: index.html and README.md.
Add: hangul.html, home.css, navigation.css, the unit2 folder,
and audio/Ch2 (numbers, vocabulary, expressions, grammar).

Keep the existing style.css, script.js, quiz.js, and the original 70 files
directly within audio/. Their contents are preserved in this package.
You can upload the complete package contents together if that is easier.

Use your existing GitHub Pages repository and publishing configuration.
After publishing, your existing site URL opens the new home page.

## Suggested checks
- Open both sections from home; return home and switch between sections.
- Try all three Hangul categories and complete a listening quiz.
- Try all Unit 2 categories; check question/answer Expressions cards.
- Check grammar examples, blue particles, and the phone-number practice.
- Complete Unit 2 quizzes several times; confirm new generated numbers.
- After publication, repeat the checks on a phone.

The original backup ZIP should be kept separately for restoring the old app.
