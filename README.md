# Hangul Listening Cards

A static flashcard prototype with 70 recorded audio clips. Open `index.html` to study locally, or upload the entire folder contents to a GitHub Pages repository. Keep `audio/` beside `index.html`.

The three sections are Vowels (21), Consonants in CV Syllables (38), and CVC Syllables (11). The card order and audio filenames match `Hangul_Review_70_Card_List.xlsx`.

To publish from a repository root: upload `index.html`, `style.css`, `script.js`, and `audio/`; in repository Settings → Pages choose Deploy from a branch, the `main` branch, and `/ (root)`. Then test the published link, especially audio on a phone.

The Listening quiz selects four distinct cards from each section, shuffles all 12 questions, and presents four answers per question. Close choices are curated where useful; common same-sound spellings are excluded from the same answer set. Students can replay audio, see the correct answer after choosing, and start a fresh quiz at the end.
